# 现代汉语专题练习

一个可直接在浏览器打开的单页练习工具，页面源文件为 [`index.html`](index.html)。当前页面内置 41 道题，分为汉字、字音、字形、标点和成语五类。

## 使用

打开 `index.html` 即可练习。页面提供按类别轮询、全部随机和指定类别练习；作答后显示正确答案与题目解释。键盘可用 A-F 或 1-6 选择选项，按 Enter 进入下一题。

页面会优先加载同目录下的 `题库数据.js`，但本仓库目前没有该文件；实际使用的是 `index.html` 内的回退题库。新增或修订题目时，应核对题干、答案及解释，再同步维护回退数据。

## 题目与使用边界

页面内的题库元数据标注了《现代汉语专题训练》，部分题目另标注试题来源。仓库没有提供原始教材或完整授权说明；公开使用和转载题目时应核对相应来源与使用许可。仓库目前也没有独立开源许可证。
